## 3. まだ一致していない点

1. ヒーローの写真は album cover（PDFの専用スタッキング写真ではない）
2. 商品名・価格は現行カタログ（Light等のPDFサンプル名ではない）
3. ページ数は basePages 刻み（PDFの24/36/48ではない）
4. 送料は現行 ¥550（PDFの送料無料サンプルではない）
5. 保存カード下4桁の実データなし
6. Apple Pay等は見た目のみ
7. 発送完了画面は未表示（Provider未接続）
8. 手書きフォントは serif 近似
9. PDFの花装飾は軽量ブラーで代替
