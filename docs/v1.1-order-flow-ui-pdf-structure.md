## 共通

- Bottom Nav: **なし**
- Header: 戻る（‹）+ 中央タイトルのみ
- Step: ①商品選択 ②確認 ③完了（番号丸 + 下ラベル + 接続線）
- 背景: warm ivory
- 主色: muted terracotta
- カード: 白〜薄い暖色ブロック + 極薄 border、強い shadow なし

## 07.4 商品選択（p.14）

1. Header「フォトブックを注文」
2. Step 1 active
3. Hero: 横長ブロック（左=本スタック写真 / 右=短いコピー2行）
4. 「商品を選択」+ 3カード横並び（本・名前・短い説明・価格・仕様）選択=テラコッタ枠+✓
5. 「ページ数を選択」+ 丸チップ
6. 「オプション」+ checkbox行（ギフト / メッセージ）
7. 合計金額行
8. CTA「注文内容を確認する →」（幅ほぼ一杯・高さ48–52）

## 08.1 注文内容の確認（p.15）

1. Header「注文内容の確認」 / Step 2
2. 商品カード: 左=縦長表紙 / 右=タイトル・説明・仕様4行 / 「仕様を変更する >」
3. お届け先: アイコン+氏名住所 / 「変更」
4. お支払い方法: カードアイコン+Visa **** / 「変更」
5. 注文概要: 商品・オプション・送料・合計（テラコッタ大）
6. CTA「注文を確定する →」
7. 利用規約テキスト

※配送先未入力時は編集フォームを展開。確認画面の見た目を優先。

## 08.2 お支払い（p.16）

1. Header「お支払い」 / Step 2
2. 支払い方法: ラジオ行（クレカ選択 / Apple Pay / Google Pay / Paidy）
3. 注文内容: 小さい表紙+仕様+「内容を変更する >」
4. 合計金額
5. CTA「今すぐ支払う」（鍵アイコン）→ Stripe Checkout

※実決済手段選択は Stripe へ委譲。見た目のみ PDF 準拠。
