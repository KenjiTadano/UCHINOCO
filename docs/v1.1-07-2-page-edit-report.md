## 3. 画面構成（To Be 準拠）

1. Header: 戻る /「ページを編集」/「完了」
2. ページ番号: `6 - 7 / 24` 形式（現在見開き / 総ページ）
3. BookSpread + 左右 Arrow
4. 見開き thumbnail 横並び（選択中 terracotta）
5. このページの写真（実 photo cards + X /「写真を変更」）

## 4. Layout selector（即時反映）

| UI | BookSpread layout | 概要 |
|---|---|---|
| レイアウト1 | `G` | 左 large + 右 stacked |
| レイアウト2 | `F` | 左 text + 右 large / small×2（To Be 主レイアウト） |
| レイアウト3 | `E` | 既存 E |

album_photos / Supabase / 新テーブルは触らない（UI のみの layout preview）。

写真 X も同様にローカル remap のみ（サーバーの remove ロジックは呼ばない）。
