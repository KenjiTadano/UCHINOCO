## 注文フロー画面構造（実画像ベース）

### p14 07.4 商品選択
1. Header: ‹ / 「フォトブックを注文」
2. Step 1 active（円+線+ラベル）
3. Hero: 左=本スタック写真 / 右=コピー2段 / 暖色ブロック
4. 「商品を選択」+ 3縦カード（選択=テラコッタ枠+✓）
5. 「ページ数を選択」+ チップ
6. 「オプション」+ チェック行2つ（ギフト / メッセージ）
7. Sticky: 合計金額 + CTA「注文内容を確認する →」
8. **Bottom Nav なし**（下端まで ivory）

計測:
- CTA帯 y≈928–978 → **高さ ≈51px**
- CTA x≈19–364 → **左右マージン ≈19px**（384幅）
- CTA色 ≈ `#b36048`

### p15 08.1 注文確認
Header → Step2 → 表紙+仕様 → お届け先 → お支払い → 注文概要 → CTA「注文を確定する →」→ 規約文 / Navなし

### p16 08.2 お支払い
Header → Step2 → 支払い方法ラジオ → 注文内容 → 合計 → CTA「今すぐ支払う」 / Navなし

### p17 08.3 制作中
Header「注文完了（制作中）」→ Step3 → 感謝大見出し → 線画+手書き文 → 4段階進捗 → 説明 → outline「注文履歴を見る」→ 次アクション / Navなし

### p18 08.4 発送完了
Header → Step3 → 発送メッセージ → 本モック+吹き出し → 配送カード → SNS → 「ホームに戻る」 / Navなし
