## Root cause / existing behavior

The draft branch of AlbumPreviewScreen placed DraftSpreadView inside an unsized flex item. The child uses percentage-based width and aspect-ratio, while its visual layers are absolutely positioned. The unsized wrapper's intrinsic width collapsed, giving the main wrapper and renderer 0 × 0 dimensions in the deployed Preview. Consequently the stage also had zero height. Its absolutely positioned arrows (top: 50%, translateY(-50%)) overlapped the immediately following thumbnail rail.

The rail intentionally scrolls horizontally; a partial trailing item is not by itself permanent clipping. Its former 2px horizontal padding and hidden scrollbar made the boundary difficult to distinguish. The investigation did not establish that the final item was permanently unreachable before this fix.

Git comparison with Task082.1 (50be724 and its parent) showed the unsized main wrapper and digital width expression already existed. Task082.1 changed thumbnail rendering, but did not introduce that main sizing structure. Do not attribute the original 0 × 0 bug specifically to Task082.1 without additional historical runtime evidence.

## Minimal fix

- Added album-preview-main-canvas to the existing main wrapper: width 100%, min-width 0, max-width 362px. The containing stage already has a definite width and the same desktop cap. No fixed height or new aspect-ratio math; the existing DraftSpreadView geometry supplies height naturally.
- Increased Preview body horizontal padding from 12px to 16px. At 375px the canvas is 343px wide; the desktop 362px cap remains intact.
- Kept arrows anchored to the main stage, which now obtains height from its in-flow canvas. Moved left/right offsets from -8px to 0, and increased both touch dimensions from 36px to 44px.
- Increased rail horizontal padding to 12px and set scroll-padding-inline to 12px. Retained horizontal scrolling, non-shrinking items, and existing renderer path. No scroll snap behavior was changed.
- Existing body Preview order is unchanged: header, location, main, rail, section selector, print link, primary CTA, secondary CTA.
