## 12. まだPDFと違う箇所

1. オプション料金が Stripe に乗らない（業務ロジック変更禁止のため）
2. 保存済みカード下4桁の実データなし
3. Apple Pay / Google Pay / Paidy は見た目のみ（実選択は Stripe）
4. ヒーローの「本が重なった写真」は album cover で代替
5. 商品カタログ名/価格は Standard / Premium / Premium Plus のまま
6. 送料は現行 ¥550（PDFの送料無料サンプルではない）
7. 発送完了画面は未表示
8. SNSシェアは見た目のみ（機能なし）
