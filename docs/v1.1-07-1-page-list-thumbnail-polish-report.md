| 項目 | 描画 |

共通コンポーネント構成は維持。今回は見た目の最終調整のみ。

---

## 2. 今回の polish 内容

### 見開き thumbnail
- book preview をカード幅に対して **+4%**（`width: 104%`）に調整（前回の +7% から抑えめ）
- カード内上下 padding を `0` に近づけ、余白を削減
- PageSurface 内 padding / gap をわずかに詰め、左右ページの写真・タイトルが読みやすくなるよう調整

### 表紙 thumbnail
- サイズ感はおおむね維持（`width: 76%`）
- 見開きと **同一 aspect にはせず**、cover 側だけ inset padding で視覚的な高さ差を微調整

### Grid / 一覧性
- 3列維持
- 下段（例: 6–7 / 8–9）の行間を `row-gap: 12px` に整理
- 強制クリップ用の `max-height` / 下端 mask / CTA グラデーションを外し、9ページ分（表紙 + 見開き4）が自然に並ぶようにした

### Labels
- 位置（thumb 直下 `gap: 3px`）・`font-size: 11px` は維持
- `min-height` / `text-align: center` で `1 表紙` / `2 - 3` / … の見え方を揃えた
