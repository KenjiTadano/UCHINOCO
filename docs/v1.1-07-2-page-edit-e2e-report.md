## 1. 原因（なぜ全部動かなかったか）

1. **pointer-events / stacking**  
   BookSpread に `filter: drop-shadow` があり stacking context が矢印を覆う。矢印が「見えるが押せない」状態になり得た。  
   → book 全体 `pointer-events: none`、arrow `z-index: 30`。

2. **写真を変更が Link 遷移のみ**  
   `/add` へ飛ばすだけで、見開きへの即時差し替え UI が無かった。  
   → ローカル picker sheet を実装。

3. **見開きが 1 つしか無いアルバム**  
   06.3 の packing（3枚→1見開き）だと thumbnail / Arrow 切替を検証できない。  
   → 07.2 専用 `buildAlbumEditSpreads`（1–2枚ごとに見開き）を追加。06.3 packing は未変更。

4. **E2E で使っていた pet/album ID が別ユーザー用で 404**  
   実セッションのアルバムへ差し替え。

5. **完了 / 戻る**  
   Link 自体はあったが、上記と合わせて押下確認を E2E で担保。
